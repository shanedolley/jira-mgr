# Tutorials

Lessons that take a newcomer from nothing to a working result. Each arrives with the first code it teaches.

These pages are not written yet; [#101](https://github.com/shanedolley/jira-mgr/issues/101) tracks them.

| Tutorial | Teaches | Planned for |
|---|---|---|
| `getting-started.md` | Installing Node and pnpm, building the repo, logging in with `jm auth login` and listing issues | CLI |
| `first-agent-session.md` | Having an agent read the issue tree and edit a field through `jm --json` | CLI |

## Node Version

jira-mgr needs Node 24; install it with `nvm install 24 && nvm use 24` if `node --version` shows an older release. `getting-started.md` will carry this step.
