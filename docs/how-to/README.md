# How-To Guides

Recipes for one task each, for a reader who already knows the codebase.

| Guide | Task |
|---|---|
| [`install-cli.md`](install-cli.md) | Build `jm` and link it with `npm link` |
| [`install-desktop-app.md`](install-desktop-app.md) | Package the unsigned app, install it, open it, find its state and uninstall it |
| [`run-tests.md`](run-tests.md) | Run each test suite and debug a failure |
| [`refresh-fixtures.md`](refresh-fixtures.md) | Record PSAPAC response bodies as they are and update the MSW fake |
| [`run-live-tests.md`](run-live-tests.md) | Run the read-only PSAPAC tests with `JM_LIVE_JIRA=1` |
| [`add-cli-command.md`](add-cli-command.md) | Add a command to the schema, with a handler, a test and the regenerated reference |
| [`desktop-development.md`](desktop-development.md) | Run, debug and build the Electron app |
| [`add-shortcut.md`](add-shortcut.md) | Add a single-key shortcut to the keymap |
