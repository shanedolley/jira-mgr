# How-To Guides

Recipes for one task each, for a reader who already knows the codebase. Each arrives with the first code it describes.

| Guide | Task | Written in |
|---|---|---|
| `run-tests.md` | Run each test suite and debug a failure | Core |
| `refresh-fixtures.md` | Record PSAPAC response bodies as they are and update the MSW fake | Core |
| `run-live-tests.md` | Run the read-only PSAPAC tests with `JM_LIVE_JIRA=1` | Core |
| `add-cli-command.md` | Add a command to the schema, with `--json` output, an exit code and an end-to-end test | CLI |
| `install-cli.md` | Build `jm` and link it with `npm link` | CLI |
| `desktop-development.md` | Run, debug and build the Electron app | Desktop |
| `add-shortcut.md` | Add a single-key shortcut and its palette entry | Desktop |
