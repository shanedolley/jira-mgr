# Standards

Every contributor, human or agent, follows these. A pull request that breaks one either fixes the code or changes the standard in the same pull request.

| Standard | Covers |
|---|---|
| [Git Workflow](git-workflow.md) | Branches, commits, merging and versioning |
| [Code Review](code-review.md) | The pull request process and the definition of done |
| [TypeScript](typescript.md) | Compiler settings, modules, types and validation |
| [React](react.md) | Components, state with TanStack Query, and accessibility |
| [Testing](testing.md) | What to test, where, with which tool, and how Jira is faked |
| [Errors and Logging](errors-and-logging.md) | Error codes, CLI exit codes and logs |
| [Naming](naming.md) | Names for files, code, packages, environment variables and the CLI |
| [Dependencies](dependencies.md) | Adding, updating and removing packages |
| [Documentation](documentation.md) | Where docs go and how to write them |
