# Design

Design docs written before a large feature is built: the problem, the proposed design, the alternatives, and the open questions. Write one when a feature spans more than a week of work or more than one package. The CLI command schema and the issue tree are written; the editor's doc (0003) rides on the `d4-editor` branch until D4 merges.

Name each `NNNN-short-title.md`, numbered in order, and start from [the template](../templates/design-doc.md). A design doc records intent; once built, the code and `docs/architecture/` describe what exists, and any lasting decision moves to an ADR.
