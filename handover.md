## Traps

- **Scrollbar gutters differ between Linux CI and macOS** (2026-10-12, met on PR #190; cost: one CI round). Linux CI uses classic 15px scrollbars and macOS e2e uses overlay scrollbars with a 0px gutter, so an exact-width assertion on an element inside a scroller passes locally and fails on CI. Measure the gutter as `offsetWidth - clientWidth` of the scroller.
- **A release before the write is held is lost** (2026-10-11, met on main CI run 38088593493 after PR #170, fixed by PR #171; cost: a red main and a fix PR). The e2e fake's `releaseEdit` is `held.shift()?.()` (`apps/desktop/src/main/e2e-fake.ts:1447`, re-read 2026-10-11T05:09Z), so releasing before the create write is held does nothing and the dialog waits forever. In e2e, wait for the write (`settle(n)` or `expect.poll(writes)`) before `releaseEdit`. The race did not reproduce locally under CPU throttle (rate 20) or ten busy loops, 12 and 16 runs of the unfixed tests passing.
- **A copied worktree folder moves the original's HEAD** (2026-10-11, met by 147-search-review; cost: the #147 worktree's HEAD detached, repaired at once). A copied worktree folder keeps its `.git` file pointing at the original's gitdir, so `git checkout` in the copy moves the original worktree's HEAD.
