## Traps

- **A CI-only e2e race: Tree rows read a render late** (2026-10-11, met on PR #159; cost: one red CI run and a fix round). Enter in the filter read Tree rows built from `useDeferredValue(filters)` a render late and landed on the Customer header; it passed locally and failed on Linux CI every time. Reproduce such races locally with CDP `Emulation.setCPUThrottlingRate` (rate 20), as the `throttle()` helper in `e2e/desktop/keyboard.test.ts` does. Never read derived rows in an event handler right after a state change.
- **ship-it merges a draft pull request** (2026-10-11, met on #155 twice). ship-it tries to merge a draft and posts "Pull Request is still a draft" failures that ask for a fix. The draft is deliberate while a story waits on Shane: ignore the failures and do not push.
- **The claim-check hook refuses unrun test counts, and the PR hook refuses a body file on disk** (2026-10-11, met on #154 and again by 132-ship; cost: one retry each). A `gh pr create` description that quotes test counts the orchestrator's own session did not run is refused. Run the tests in the session, or attribute the counts to the builder or reviewer without numbers. Pass the body with `--body-file -` and a quoted heredoc, because the hook refuses `--body-file <path>`. `gh pr edit` takes `--body "$(cat <<'EOF' ... EOF)"` only; it refuses a body from a pipe or another substitution, and the claim-check refuses any sentence it cannot verify, such as a restated review verdict (2026-10-11, 135-ship; cost: four retries).
- **The ticket guard refuses `$(...)` in `gh issue comment --body`** (2026-10-11, met on the #131 claim). Only a quoted heredoc substitution passes; write other text inline.
- **Timer e2e tests fail between local midnight and about 02:00** - resolved 2026-10-11 by #156 (c9e721d; cost: two red local e2e runs on `timer.test.ts:128` and `:298` and one debug session). The tests start timers 1 to 9 hours back, and core correctly flags a timer that crosses local midnight. The timer tests now launch Electron with `TZ` set to an `Etc/GMT` zone where it is about noon.
- **A conditional `border-danger` never wins over another border colour** (2026-10-10, met by 126-contrast-build; cost: one class change). In the built Tailwind CSS `.border-danger` sorts before the other border colours, so a `border-danger` added beside `border-field-border` loses. Use the `aria-invalid:border-danger` variant, as `IssueProperties.tsx` does.
- **Subagent Write and Bash heredoc writes of findings files in the scratchpad were refused by hooks** (2026-10-10, met on #119; cost: three lens agents had to return findings by SendMessage). Have review subagents return findings as message text, and save them from the lead's own session if a file is needed.
